# Лабораторна робота 16: Збереження стану додатку в Web Storage (localStorage) та перемикання теми

## Опис роботи
У цій лабораторній роботі реалізовано довготривале збереження користувацьких даних у браузерному сховищі `localStorage` (стан кошика, список обраних товарів та вибір теми оформлення) для забезпечення безперервності взаємодії користувача між перезавантаженнями сторінки.

---

## Що було зроблено:
- синхронізація кошика з `localStorage` - реалізовано збереження масиву кошика за ключем `techshop_cart`, автоматичне відновлення при старті (`loadCartFromStorage`) та очищення кнопкою «Очистити кошик» (`clearCart`);
- збереження списку обраного (Favorites) - додано збереження ID перетягнутих через Drag and Drop товарів у сховище (`techshop_favorites`), їх візуалізацію у Drop Zone та можливість видалення;
- перемикання теми оформлення (Dark/Light) - реалізовано модуль `theme.js` з кнопкою перемикання, збереженням вибору в `techshop_theme` та перевіркою системних налаштувань ОС через `matchMedia('(prefers-color-scheme: dark)')`;
- підтримка CSS-змінних для теми - налаштовано змінні кольорів у `:root` та `body.dark-theme` (`--bg-primary`, `--bg-card`, `--text-main`, `--border-color`) із плавними переходами `transition`;
- безпечна робота з Web Storage - додано захист `try...catch` при серіалізації та парсингу JSON для запобігання збоям при пошкоджених даних.

## Підсумок
Робота закріпила навички використання Web Storage API (`localStorage`): збереження, зчитування та видалення серіалізованих даних, керування станом кошика й списку обраного, а також створення перемикача темної та світлої тем оформлення.
