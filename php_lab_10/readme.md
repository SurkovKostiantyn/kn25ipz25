# Опис проекту (PHP Сесії та Авторизація)

Цей проект демонструє базовий механізм авторизації користувачів за допомогою сесій в PHP.

Опис файлів:
- `index.php` - головна сторінка, на якій розміщена форма для входу. Якщо користувач вже авторизований, замість форми показується посилання на кабінет;
- `login.php` - обробник форми авторизації. Перевіряє введені email та пароль, і якщо вони вірні — створює сесію та перенаправляє в кабінет;
- `cabinet.php` - захищена сторінка "Особистий кабінет", доступ до якої мають лише авторизовані користувачі (перевіряється наявність сесії);
- `logout.php` - скрипт деавторизації, який повністю очищує та знищує поточну сесію, після чого повертає на головну сторінку;
- `navigation.php` - файл з HTML-кодом меню навігації, який підключається до інших сторінок через `include`, щоб уникнути дублювання коду;
- `style.css` - файл з максимально базовими стилями для оформлення сторінок.
