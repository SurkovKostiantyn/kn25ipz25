# Лабораторна робота 13: Робота з зовнішнім REST API (Fetch API) та динамічні дані

## Опис роботи
У цій лабораторній роботі здійснено перехід від локального статичного масиву даних до отримання даних із зовнішнього сервера через REST API (FakeStore API). Реалізовано асинхронне надсилання HTTP-запитів за допомогою функції `fetch()`, опрацювання відповідей у форматі JSON, відображення розширеної інформації про товари та обробку помилок мережі.

---

## Що було зроблено:
- надсилання мережевого запиту до FakeStore API - налаштовано асинхронний GET-запит до ендпоінту `https://fakestoreapi.com/products?limit=2` через функцію `fetch()`;
- валідація статусу HTTP-відповіді - реалізовано перевірку прапорця `response.ok` та генерацію винятку зі статусом у разі збою;
- розпакування даних з формату JSON - застосовано метод `await response.json()` для асинхронного перетворення відповіді у масив JavaScript-об'єктів;
- збереження даних у глобальний масив - отриманий список товарів записується у змінну `globalStoreProducts` для подальшої обробки та вибору товарів;
- адаптація розмітки під структуру API - оновлено генерацію карток товарів із виведенням категорії, рейтингу `product.rating.rate`, опису та ціни у доларах;
- обробка помилок завантаження - блок `try...catch` перехоплює збої з'єднання, логує їх через `console.error` та виводить зрозуміле повідомлення про помилку користувачеві.

## Підсумок
Робота закріпила на практиці використання сучасного Fetch API у JavaScript: виконання GET-запитів, роботу з промісами через синтаксис async/await, десеріалізацію JSON-даних та динамічне наповнення інтерфейсу на основі зовнішнього REST API.
