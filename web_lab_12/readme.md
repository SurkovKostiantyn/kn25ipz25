# Лабораторна робота 12: Модальне вікно кошика покупок та управління його станом

## Опис роботи
У цій лабораторній роботі реалізовано спливаюче модальне вікно (Popup / Modal) для відображення кошика покупок. Користувач може відкривати кошик натисканням кнопки в шапці сторінки, переглядати список доданих товарів із підрахунком їхньої кількості та вартості, а також закривати вікно кнопкою або кліком по затемненому фону поза його межами.

---

## Що було зроблено:
- розмітка модального вікна - додано контейнер затемнення `.modal-overlay` та блок самого вікна `.modal-window` із заголовком, списком товарів `#cartItemsContainer` і підвалом із загальною сумою;
- стилізація оверлею та вікна - налаштовано фіксоване позиціонування `fixed`, напівпрозорий фон `rgba(0, 0, 0, 0.5)`, вирівнювання по центру через flexbox та прокручування вмісту через `overflow-y: auto`;
- відкриття вікна за кнопкою кошика - створено функцію `openCartModal()`, яка видаляє службовий клас `.hidden` при натисканні на `.btn-cart`;
- закриття модального вікна - створено функцію `closeCartModal()`, яка повертає клас `.hidden` при натисканні на кнопку `#closeCartBtn`;
- закриття кліком по фону - додано слухач події `click` на оверлей, який перевіряє `event.target === cartOverlay` та закриває вікно при кліку повз нього;
- динамічний вивід списку товарів у кошику - у функції `updateUI()` налаштовано генерацію елементів у контейнері `#cartItemsContainer` із зазначенням назви, кількості та підсумкової вартості кожної позиції.

## Підсумок
Робота дозволила закріпити на практиці створення інтерактивних модальних вікон у JavaScript: керування класами видимості, обробку подій кліку по оверлею та динамічну генерацію вмісту кошика в межах модального вікна.
