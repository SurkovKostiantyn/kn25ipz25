# Лекція 8: Робота з файлами у PHP (Завантаження файлів на сервер)

## Тема лекції:
- завантаження файлів через форму - використання атрибута `enctype="multipart/form-data"`;
- робота з масивом `$_FILES` - структура масиву та перевірка коду помилок;
- валідація файлу - обмеження розміру та перевірка дозволених розширень;
- безпечне збереження - генерація унікального імені через `uniqid()` та функція `move_uploaded_file()`;
- сканування директорії - отримання списку файлів через `scandir()` та виведення посилань.

## Ключові поняття лекції

### 1. Спеціальне кодування форми (`enctype`)
Для надсилання файлів звичайної форми недостатньо. Обов'язково вказується атрибут `enctype="multipart/form-data"`:

```html
<form action="upload.php" method="POST" enctype="multipart/form-data">
    <input type="file" name="avatar" accept="image/png, image/jpeg" />
    <button type="submit">Завантажити</button>
</form>
```

- метод форми - обов'язково `POST`;
- атрибут `enctype` - вказує браузеру розділити запит на частини та передати бінарні дані файлу;
- поле `<input type="file">` - дозволяє користувачеві обрати файл на своєму комп'ютері;
- атрибут `accept` - фільтрує типи файлів у вікні вибору файлу в браузері.

---

### 2. Суперглобальний масив `$_FILES`
Файли не потрапляють у `$_POST`, вони зберігаються у спеціальному масиві `$_FILES`.

Структура елемента `$_FILES['avatar']`:
- `name` - оригінальна назва файлу на комп'ютері клієнта (наприклад, `photo.jpg`);
- `type` - MIME-тип файлу, переданий браузером (наприклад, `image/jpeg`);
- `tmp_name` - тимчасовий шлях до файлу на сервері у системній папці;
- `error` - числовий код помилки (`0` або константа `UPLOAD_ERR_OK`, якщо все добре);
- `size` - розмір завантаженого файлу в байтах.

---

### 3. Валідація та безпека
Перед переміщенням файлу обов'язково виконується перевірка:

- перевірка на помилки - умова `$file['error'] === UPLOAD_ERR_OK`;
- перевірка за розміром - обмеження максимального розміру в байтах:
  ```php
  $maxSize = 20 * 1024 * 1024; // 20 МБ
  if ($file['size'] > $maxSize) {
      die("Файл завеликий! Максимум 20 МБ.");
  }
  ```
- перевірка за розширенням - «білий список» дозволених форматів за допомогою `pathinfo()`:
  ```php
  $allowedExtensions = ['jpg', 'jpeg', 'png', 'gif'];
  $ext = strtolower(pathinfo($file['name'], PATHINFO_EXTENSION));
  if (!in_array($ext, $allowedExtensions)) {
      die("Дозволено завантажувати ТІЛЬКИ картинки (jpg, png, gif)!");
  }
  ```

---

### 4. Генерація імені та переміщення файлу
Ніколи не можна зберігати файл під оригінальною назвою клієнта, щоб уникнути конфліктів імен та завантаження небезпечних скриптів:

- генерація унікального імені - функція `uniqid('avatar_', true) . '.' . $ext`;
- збереження на диск - функція `move_uploaded_file($tmpPath, $destination)`:
  ```php
  $destination = 'uploads/' . $newName;
  if (move_uploaded_file($file['tmp_name'], $destination)) {
      echo "Файл збережено: " . $destination;
  }
  ```

---

### 5. Перегляд вмісту директорії
Для читання списку збережених файлів використовується функція `scandir()`:

```php
$dir = 'uploads/';
$files = scandir($dir);

foreach ($files as $file) {
    if ($file === '.' || $file === '..') {
        continue;
    }
    echo "<li><a href='uploads/$file'>$file</a></li>";
}
```

- функція `scandir($dir)` - повертає масив імен усіх файлів і папок у зазначеній директорії;
- системні записи `.` та `..` - позначають поточну та батьківську директорії й пропускаються за допомогою `continue`.
